# Monogit v0.2.7

## Highlights

- Reduced repository status and detail refresh subprocesses by using aggregated Git snapshots and removing duplicate refreshes.
- Added focused single-pane rendering below 80 columns, responsive configuration rows, and Unicode-aware truncation.
- Corrected footer hints and routed commit, branch, file, and space actions through the canonical key map.
- Made Push All skip repositories without commits ahead of upstream.
- Added discovery for valid linked Git worktrees.

## Security

- Added explicit `--` separators for user-controlled Git pathspecs.
- Refused untracked symlinks when rendering diffs and blocked detached-HEAD pushes.
- Removed credentials and query secrets from browser URLs and command logs.
- Added atomic `0600` writes for config, startup cache, and exported command logs.
- Added confirmation before command-log export and removed Windows `cmd /c` editor launching.
- Validated branch, remote, merge-tool, path, and control-character inputs.

## Validation

- `go test -count=1 ./...`
- `go test -race ./...`
- `go vet ./...`
- `govulncheck -mode=binary ./monogit` — no vulnerabilities found
