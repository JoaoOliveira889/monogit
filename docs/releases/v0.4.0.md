# MonoGit v0.4.0 Release Notes

**MonoGit v0.4.0** rebuilds navigation around Vim's model, adds a `:` command palette, cuts the cost of a full-workspace refresh by roughly twenty times, and fixes a group of long-standing correctness and safety bugs. It also moves the interface to Bubble Tea, Lip Gloss and Bubbles v2.

> **Breaking:** panel shortcuts moved from `1` / `2` / `3` to `ctrl+w 1` / `2` / `3`, and the graph toggle moved from `g` to `gl`. Both changes free `g` and the digits for Vim-style prefixes and counts.

---

## ⌨️ Vim-Style Motions
- **Counts**: any motion takes a numeric prefix, so `5j` moves down five repositories and `3ctrl+d` scrolls three half-pages.
- **`gg` / `G`**: jump to the first and last repository. `g` is now a prefix rather than an action, which is why the graph toggle became `gl`.
- **`}` / `{`**: jump to the next and previous repository that needs attention — dirty, ahead, behind, or conflicted — skipping clean ones and wrapping around the filtered list.
- **`ctrl+o` / `ctrl+i`**: retrace the cursor's path through the jump list, the way Vim's jumplist works.
- **`.`**: repeat the last action on the selected repository. Only actions that need no further input are repeatable, so a stale commit message or branch name can never be replayed.
- **Which-key panel**: pressing a prefix such as `g` or `ctrl+w` lists the keys that can follow it, so sequences are discoverable rather than memorised.
- **Relative line numbers**: off by default. Turn them on with `:relativenumber` or in the configuration panel to read a motion count straight off the list — the repository marked `4` is `4j` away.

---

## 🎛️ Command Palette (`:`)
- **Commands by name**: `:fetch-all`, `:pull-all`, `:push-all`, `:stash-all`, `:filter <status>`, `:theme <name>`, `:relativenumber [on|off]`, `:log`, `:config`, `:help`, `:quit`.
- **Unambiguous prefixes**: `:fe` runs `:fetch-all`. An ambiguous prefix lists the candidates instead of guessing.
- **Tab completion** against the highlighted entry, with `↑` / `↓` or `ctrl+p` / `ctrl+n` to move through matches.
- The palette calls the same handlers the shortcuts do, so there is one implementation per action.

---

## 🔍 Full-Screen Diff Viewer (`d`)
- **Panoramic unified diff**: Pressing `d` opens a dedicated full-screen viewer with changed files on the left and the selected file's unified diff on the right.
- **Line numbers & gutters**: Clear old and new line numbers, hunk headers, and per-file +/- change counters.
- **Navigation & hunk jumping**: Use `j` / `k` to move between changed files, and `J` / `K` to jump directly between diff hunks.
- **Inline staging**: Press `space` on any file in the diff tree to stage or unstage its changes immediately.
- **Safe discarding & clipboard**: Press `x` to discard file modifications (with confirmation safeguard) and `y` to copy the diff content.

---

## ⚡ Performance
- **Startup is no longer quadratic.** Panels were re-rendered once per status message, so scanning 100 repositories rendered the full list 100 times. Rendering is now deferred to one pass per frame: **36.7 ms and 367k allocations drop to 2.4 ms and 24k**.
- **Overlay frames cost 11× less.** The header, body and footer were assembled before checking whether a modal would replace the whole frame: **1.35 ms to 0.12 ms** per keystroke with a modal open.
- **Only visible rows are styled.** The repository and file lists styled every row regardless of the viewport window; rows outside it are left blank, so the viewport still counts them for scrolling and the scrollbar.
- **Fewer syscalls and network calls.** Working-directory checks are cached for 15 seconds instead of running `stat` on every Git invocation, and the unpushed-tag probe — which hits the network via `ls-remote` — no longer fires for prefetched neighbours.

---

## 🐛 Correctness Fixes
- **Cherry-pick and revert reported nothing.** Neither message was listed in the update dispatcher, so both silently dropped their result and left the repository pinned as committing, which kept the spinner animating at 80 ms indefinitely.
- **`j` and `k` could not be typed in the repository search.** Both were consumed as cursor movement before the text input saw them. Cursor movement in search now uses the arrow keys and `ctrl+n` / `ctrl+p`.
- **Renamed files showed the old path.** `git status --porcelain -z` emits `<new>\0<old>\0`, so the parser resolved to the original path and its diff came back empty.
- **Discarding a staged file left it staged.** The index is now restored alongside the working tree.
- **Panels grew past their given height and pushed the footer off screen.** Lip Gloss line wrapping and tall blocks are now strictly truncated to each panel's exact box, keeping the status footer visible across all terminal dimensions.
- **Footer hints audited and unified.** Obsolete or misleading bindings were removed, and Esc in the detail panel now cleanly returns to the repository list.
- **`Push all` always claimed success**, ignoring per-repository failures.
- **Interactive rebase could not rebase every commit.** Rebasing all reachable commits now uses `--root` instead of an out-of-range `HEAD~N`.
- **Opening a terminal editor in iTerm always failed** — its AppleScript closed a `tell` block with `end if`.

---

## 🔒 Safety
- **Interactive rebase now requires confirmation**, like every other mutating action. It rewrites history and previously ran straight from `enter`.
- **No user-controlled text reaches a shell.** `GIT_SEQUENCE_EDITOR` built a `cp` command as a shell string; MonoGit now re-invokes itself through an internal flag with shell-quoted paths. Every rebase item is validated, closing a path where a newline in a commit message could append an `exec` line to the rebase todo list.
- **Worktree terminal paths are passed as arguments** rather than interpolated into AppleScript, so no part of a path is ever parsed as script or expanded by a shell.
- **Commit messages may contain `` ` `` and `$`.** These were rejected by a shell-escaping rule that never applied, since Git is invoked with discrete arguments.

---

## 🏗️ Internal
- **Interface state is no longer a pile of booleans.** Five flags describing what the right-hand panel shows collapse into one `detailView` value, and eight modal flags become one overlay stack where the innermost layer owns the keyboard and `esc` unwinds one layer at a time. Key dispatch and rendering now read the same structure instead of two if/else chains that had to agree.
- **Charm v2**: migrated to `charm.land/bubbletea/v2`, `lipgloss/v2` and `bubbles/v2`. Lip Gloss v2 counts borders and padding inside `Width`, which had been silently rendering every panel two columns narrower than its own title line.
- **Duplication removed**: terminal emulator selection existed in two places with diverging behaviour, including two copies of the Ghostty check that disagreed on whether `~/Applications` counts.
- Benchmarks now cover the startup burst, cursor movement and overlay frames, and an end-to-end test drives the dashboard against real repositories.
