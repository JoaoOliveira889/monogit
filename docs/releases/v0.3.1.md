# MonoGit v0.3.1 Release Notes

**MonoGit v0.3.1** improves responsiveness after Git actions while hardening untracked-file handling.

---

## Faster interaction

- A single `stash`, `pull`, `push`, checkout, merge, cherry-pick, or revert refreshes only its repository. Bulk operations still refresh every affected repository.
- Repository-list status snapshots now use one Git process instead of a separate status and commit-log process.
- Detail data is reused for five seconds while moving between repositories. Cached detail restores immediately without leaving the loading state active.

## Security and maintenance

- Untracked-file diff and discard reject a path that escapes the repository through a symlinked parent directory.
- Updated terminal/UI transitive dependencies.
- `go test ./...`, `go vet ./...`, `go mod verify`, and `govulncheck ./...` pass.
