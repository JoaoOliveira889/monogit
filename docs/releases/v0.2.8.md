# Monogit v0.2.8

## What's New

### 🔀 Interactive Rebase (`R`)
- Full interactive rebase panel triggered by pressing `R` on any repository.
- Renders the recent commits in chronological order with customizable actions:
  - `p`: `pick` (keep commit)
  - `s`: `squash` (combine into previous commit)
  - `f`: `fixup` (combine into previous commit, discard message)
  - `r`: `reword` (edit commit message)
  - `d`: `drop` (delete commit)
- Reorder commits dynamically with `J` / `K` (or `Shift+Down` / `Shift+Up` / `ctrl+j` / `ctrl+k` / `+` / `-`).
- Non-blocking background execution with automatic todo sequence file generation via `GIT_SEQUENCE_EDITOR`.

### 🔒 Security & Refactoring
- Escaped AppleScript paths (`escapeAppleScriptString`) for `openWorktreeTerminalCmd` to prevent script injection vectors on macOS.
- Unified parallel snapshot goroutine types (`gitResult`) and error checks (`isEmptyRepoError`).

### ⚡ Performance & Design
- Cached repository filtering results (`filteredReposCache`) for instant keyboard responsiveness.
- Zero-allocation string clipping and rune truncation optimizations (`truncateRunes` O(n)).
- Redesigned Configuration Panel with icons, visual separators, and consistent styling (`ConfigItemStyle`, `ConfigValueStyle`).
- Animated splash screen with progress bar (`█░`) and braille spinner (`⠋⠙⠹…`).
- Responsive 3-breakpoint header supporting ultra-narrow terminal windows.
- Semantic color rendering (green/red/yellow) for all statusbar messages.
