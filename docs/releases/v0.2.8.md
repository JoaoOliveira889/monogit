# Monogit v0.2.8

## Highlights

- **Worktree branch checkout guard**: selecting a branch that is already checked out in a linked worktree no longer fails with a cryptic `exit status 128` error. Monogit now detects the `IsWorktree` flag before opening the confirmation modal and handles the case gracefully.
- **Open terminal at worktree** (`enter` on a worktree branch): pressing `enter` on a worktree branch opens a confirmation modal displaying the worktree path. Confirming opens a **new terminal window already positioned in that directory**. On macOS, `$TERM_PROGRAM` is used to pick the right app (iTerm2 or Terminal.app); on Linux the `$TERMINAL` env var is respected with `xterm` as fallback.
- New `GetWorktreePath` method on the `BranchManager` / `RepositoryOperator` interfaces, backed by `git worktree list --porcelain`.
