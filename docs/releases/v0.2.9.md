# Monogit v0.2.9

**Release Date:** July 30, 2026

## 🚀 Highlights & Features

### 1. In-Terminal Editor Launching (`tea.ExecProcess`)
- Terminal-based editors (`nvim`, `vim`, `nano`, `micro`, `hx`) now launch directly in the active terminal session using Bubble Tea's `tea.ExecProcess`.
- Eliminates external terminal popups, window switching, or AppleScript permission issues.
- Fixed Ghostty macOS invocation with `-n` flag (`open -n -a Ghostty --args ...`) so `--args` are never discarded when Ghostty is already running.

### 2. Zero-Layout-Shift Fixed Header & Ecosystem Status Bar
- The header height is now locked to a constant 3 lines (`headerLine`, `styledStatus`, `border`).
- Background notifications (`fetch`, `pull`, `push`, `auto-fetch`) no longer cause dynamic vertical layout shift or push panels downwards.
- The footer remains 100% visible at the bottom of the screen at all times.
- Added a rich ecosystem status summary line when idle (`● 17 repos • 3 dirty • 1 ahead • Press ? for help`).

### 3. Redesigned Rounded Panel Borders & Brand Colors
- Panels use `lipgloss.RoundedBorder()` with seamless top corner alignment (`╭─[1]────────────────╮`).
- Active Left Panel uses the **"Mono"** wordmark brand color (`ui.ColorMono`, cyan/blue).
- Active Right Panel uses the **"Git"** wordmark brand color (`ui.ColorGit`, emerald green).
- Panel titles retain clean text formatting without inheriting list item selection background boxes.

---

## 🛠 Fixes & Improvements
- **Terminal Launchers**: Added `-n` flag support for `open -n -a Ghostty` to ensure macOS passes CLI flags correctly to active Ghostty instances.
- **Viewport Alignment**: Corrected `repeatCount` math in `renderTitledPanel` for exact top-right corner (`╮`) alignment.
- **Footer Cleanup**: Moved `Press ? for help` permanently to the header status bar and cleaned up redundant footer items.
