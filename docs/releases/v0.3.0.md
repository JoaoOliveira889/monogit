# MonoGit v0.3.0 Release Notes

**MonoGit v0.3.0** is a major visual refinement release focused on standardizing design language across panels, improving status clarity, and eliminating UI ambiguity.

---

## 🚀 Key Improvements

### 1. Unified Panel Architecture & Focus Signals
- Panels 1 (Repositories) and 2 (Details/Branches/Files) now follow the exact same visual design system.
- Active panel focus is indicated cleanly by cyan bold title headers (`[1] Repositories`, `[2] Repository · repo-name`, `[2] Branches · repo-name`), keeping border colors in subtle gray (`ColorBorder`).

### 2. Clean Selection Language
- Solid background bars (`Background(ColorHighlight)`) across all lists have been replaced with discrete cyan pointer indicators (`▶ `), bold text, and right-aligned metadata columns (`local · remote`).
- Applies consistently across Repositories, Branches, Files, Stashes, Conflicts, Configuration, and Interactive Rebase panels.

### 3. Explicit & Unambiguous Status Signals
- Solitary status numbers (such as `↓5`) have been expanded to explicit, readable indicators (`↓5 behind`, `↑2 ahead`, `✎3 dirty`, `!1 conflict`).
- Clean repository states remain silent without unnecessary icons.
- Mismatched or zero metrics (e.g. `ahead 0`, `dirty 0`) are omitted from the header workspace health bar.
- Commit history timestamps display clear context (`2d ago`).

### 4. Shortcuts Modal Redesign (`?`)
- Section divider lines (`─────`) match individual column bounds to eliminate line-wrapping artifacts and `___` text breaks.
- Automatic 3-column balancing in wide viewports prevents unnecessary scrolling.
- Keys are styled in magenta (`FooterKeyStyle`) with clean category headers.
