# MonoGit v0.3.5 Release Notes

**MonoGit v0.3.5** delivers an interactive real-time search filter for the shortcuts modal (`?` / `ctrl+p`), comprehensive protection against terminal escape sequence and bracket leaks during rapid trackpad/mouse scrolling, persistent viewport scroll positions across frames, and a complete keybinding audit.

---

## 🔍 Interactive Real-Time Shortcuts Search (`?` / `ctrl+p`)
- **Instant Filtering as You Type**: Simply press `?` or `ctrl+p` and begin typing to filter the entire shortcut catalog in real time across shortcut keys, descriptions, and category headings.
- **Match Count Indicator**: A subtle live counter badge displays total shortcuts (`54 shortcuts`) or match counts (`4/54 matches`) directly in the header bar.
- **Empty State Guidance**: If a query yields zero matches, an informative message displays (`No shortcuts matching "<query>" • Press esc to clear search`).
- **Quick Dismissal & Clear**: Pressing `esc` once instantly clears the search query without closing the modal; pressing `esc` (or `?`/`ctrl+p`) again closes the help menu and returns focus cleanly to the repository panel.

---

## 🛡️ SGR Mouse Sequence & Bracket Leak Protection
- **Zero Leaked Escape Sequences**: Resolved an issue where rapid inertia scrolling with trackpads or mouse wheels on macOS terminals caused SGR mouse escape sequences (`\x1b[<65;x;yM`) to fragment across read buffers, leaking stray `[` or numeric codes into the focused search box.
- **Seamless Scroll Translation**: Mouse wheel escape chunks (`64;...M` / `65;...M`) are intercepted by `parseLeakedMouseSeq` and converted into smooth viewport scrolling (`LineUp` / `LineDown`) instead of reaching input handlers.
- **Universal Input Guard**: Extended sequence leak protection to `handleSearchKeys` (repository search) and `handleInputKeys` (commit wizard, branch creation, tag naming), keeping all text inputs clean.
- **Strict Key Validation**: Implemented `isValidHelpSearchKey` to whitelist only alphanumeric characters, space, standard navigation keys, and search punctuation (`-`, `_`, `/`, `+`, `.`, `:`, `@`), permanently rejecting brackets (`[`, `]`), angles (`<`, `>`), semicolons (`;`), and ANSI control fragments.

---

## 🖱️ Viewport Scroll Persistence Across Frames
- **Eliminated Scroll Jumps**: Removed `viewport.New` recreations from `renderHelpOverlay`. Modal dimensions now update dynamically via `.Width` and `.Height` while preserving the user's `YOffset` scroll position across render passes.
- **Direct Modal Scrolling**: Mouse wheel and trackpad scroll events in `handleMouse` now target the help viewport immediately without triggering background repository navigation or debounces.

---

## ⌨️ Audited Keybindings & Multi-Column Balancing
- **Complete Cheat Sheet Coverage**: Added missing keybindings to the modal and documentation, including interactive rebase bindings (`p | s | f` for pick/squash/fixup, `r | d` for reword/drop, `J | K` for reordering), clipboard paste (`ctrl+v`), and confirmation dialogs (`y | n`).
- **Responsive Balanced Columns**: Columns adapt automatically to terminal width (3 columns for width ≥ 105, 2 columns for width ≥ 72, 1 column for width < 72) with greedy height balancing that keeps all categories readable.
