# MonoGit v0.3.2 Release Notes

**MonoGit v0.3.2** brings Neovim and Lazygit-inspired UI enhancements, table-structured shortcuts help, fast page navigation, smooth mouse scrolling, dynamic Git concurrency, and logging improvements.

---

## 🎨 Neovim & Lazygit-inspired Design
- **Active panel border highlighting**: Focused panels now receive vibrant border highlighting in the theme accent color, providing immediate visual feedback on window focus. Inactive panels retain subtle borders.
- **Statusline mode pills**: The header displays a Neovim/Lualine-style mode badge (`NORMAL`, `BRANCHES`, `FILES`, `DIFF`, `SEARCH`, `REBASE`, etc.).
- **Polished branch preview**: Cleaned up the selected-branch preview with dedicated status badges (`✓ Current branch (HEAD)`, `Worktree linked`) without redundant footer shortcuts.
- **Floating notifications**: Repositioned notifications to the top-right corner to keep main workspace panels stable and eliminate layout shifts.

## ⌨️ Shortcuts Help Modal Overhaul
- **Structured table layout**: Completely restructured the shortcuts help modal into an elegant two-column table (`KEY │ ACTION`).
- **Clean visual separation**: Fixed column widths and cell padding prevent text collision and line wrapping (e.g. `R Interactive rebase` vs `m Resolve merge conflicts`).
- **Precision scrollbar**: Perfected line-by-line scrollbar alignment and track rendering.

## 🚀 Navigation & Keybindings
- **Fast page navigation**: Added `ctrl+d` / `pgdown` (half-page down), `ctrl+u` / `pgup` (half-page up), `G` / `end` (jump to bottom), and `home` (jump to top) across all list-based panels.
- **Smooth mouse wheel scrolling**: Optimized mouse wheel step scrolling across commit graphs, recent activity, and shortcuts viewport.
- **Enter on repository**: Pressing `enter` on the repository list now opens/focuses the details panel (`LogPanel`).
- **Smooth panel switching (`h`/`l`)**: Pressing `h` moves focus to the repository list without abruptly cancelling the active branches or files view. Pressing `l` returns focus immediately.
- **Contextual log actions**: Key `d` directly inspects diffs, `y` copies the commit hash, and `enter` inspects files.

## ⚡ Performance & Logging
- **Dynamic Git concurrency**: Subprocess execution now respects user-configured `cfg.Concurrency` instead of a hardcoded limit.
- **Cached workspace health stats**: Eliminated redundant per-frame repository iteration in `renderWorkspaceHealth`.
- **Thread-safe logging & Debug level**: Removed lock contention from `slog.Logger` and added `Debug(...)` logging support activated via `MONOGIT_DEBUG=1`.
