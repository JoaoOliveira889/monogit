# MonoGit v0.3.3 Release Notes

**MonoGit v0.3.3** brings direct diff toggling with `d` from any panel, seamless three-column keyboard navigation, shortcut conflict resolution, and workspace-wide ignore improvements.

---

## 🔍 Direct Diff Inspection (`d`)
- **Global Diff Toggle**: Pressing `d` from the repository list (`RepoPanel`) or log panel (`LogPanel`) now immediately opens the files and diff split view for the highlighted repository.
- **Toggle Off**: Pressing `d` while viewing diffs cleanly closes the diff and files workspace and returns focus to the repository list.
- **Clean Repository Feedback**: Inspecting a clean repository with no uncommitted changes now gives clear, positive feedback with a `"Working tree clean"` status notification.
- **Footer Hints**: Added `d diff` to the contextual hints of the repository list footer.

## 🧭 Panel Navigation & Keybinding Polishing
- **Non-destructive Tab Cycling**: Pressing `tab` while in `DiffPanel` now cycles smoothly back to `RepoPanel` without destroying the active files and diff mode.
- **Three-column `h` / `l` Navigation**: Left (`h`) and Right (`l`) arrow keys now move smoothly between all 3 visible columns (`RepoPanel` ↔ `Files` ↔ `Diff`).
- **Direct Jump via `3`**: Pressing `3` when the diff panel is closed now opens the diff directly for the selected repository and focuses the diff viewport.
- **Separated Search & Status Filter**: Disassociated repository search (`/`) from the status filter modal (`ctrl+f`), updating help cards and documentation accordingly.

## 🛡️ Workspace Maintenance
- **AI Assistant Rules**: Added `CLAUDE.md` to `.gitignore` across all workspace repositories.
